ตอบ : Red bar พิสูจน์ว่าชุดคำสั่งทดสอบ (Test) ของเราสามารถทำงานและล้มเหลวได้อย่างถูกต้องเมื่อยังไม่มีฟังก์ชันรองรับ ซึ่งช่วยยืนยันว่าการเขียนเทสมีความหมายและดักจับพฤติกรรมจริงได้ ไม่ได้ผ่านตั้งแต่ยังไม่เริ่มเขียนโค้ด ซึ่งเป็นสิ่งที่ Green bar อย่างเดียวไม่สามารถพิสูจน์ได้

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
